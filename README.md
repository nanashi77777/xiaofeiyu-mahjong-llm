## 已确定的产品边界

- 标准四人日麻，优先用四人南验收，覆盖东风战及标准规则下的连庄、流局、西入等变化；按真实房间规则计算，不固定为 25000 点、固定八小局或固定结算方式。
- 模型为 `your-model-id`，渠道为 `https://model-provider.invalid/v1`，推理关闭。无预算限制，逐请求记录 token；渠道兼容性和速度需要实测。
- 麻将实时决策、重试、复盘与经验迭代共用麻将专用密钥，与QQ其他功能凭据分开；用量按凭据指纹及用途分组，旧消耗不混入新密钥。
- 实战基础计时为每次 5 秒、本小局共享 20 秒；模拟采用 5＋10。所有模型重试与点击都计入时间预算。
- 可通过QQ导航工具或本机入口登录和选场，登录失效及验证码仍需按当前状态处理；入房后不自行准备或开局，打牌接管交接仍在M9实现。物理模式需前台，可选后台模式通过浏览器鼠标事件操作，系统光标与前台不变。正常局间继续至终场，不自动开始下一场匹配。
- 只要客户端仍需要主动输入，即使仅一个合法动作，也调用模型。客户端本来就自行完成的被迫摸切只观察并标记，不冒充模型决策。
- 中断也保存；最近二十场包含进行中、完整和中断记录，终场结果与最后观察状态分开。
- 持久化采用最小事件序列，小局/和牌引用原事件；只保留一份最新缓存，QQ牌谱事件采用id/seq/kind/data。详细解释与点击日志独立。
- QQ 按需查询当前战况、历史、自己的跳满及以上和牌与经验；按当前用户请求可用专用导航工具登录/选场、查询和取消未提交指令，不逐轮自动访问或主动播报，不提供任意鼠标控制。
- 经验允许自主修订与停用；不允许自行改代码、规则或核心提示词。每场内的具体打法思路与跨场经验分别保存。
