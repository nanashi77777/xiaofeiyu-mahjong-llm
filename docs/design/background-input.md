# 后台模拟点击 · 2026-10-31增补

用户明确提出“尝试看看能不能让他在后台也可以模拟到点击”，授权新增浏览器后台输入实验。此前仅前台物理鼠标的范围随该请求扩大；保留两种模式，默认物理前台，后台模式由面板明确选择。

后台使用浏览器CDP/Playwright鼠标移动、按下、释放事件，目标仍来自可见画布截图和本家权威手牌校验，不调用游戏内部动作方法，也不构造/发送游戏操作协议。系统鼠标与前台窗口不移动。浏览器可对绑定页面模拟焦点；是否适用于Unity实际对局由服务端回执证明，不能凭DOM事件成功就宣称实际打牌成功。

继续检查已绑定窗口身份、页面host、真实状态版本、operation期限、停止与Esc。后台不适用“必须处于系统前台”检查，否则会把新需求阻断。画布截图和所有模板核验继续适用，窗口关闭/断开/错误仍暂停。

验收分别记录：后台且最小化的隔离DOM目标收到trusted事件、系统光标与前台不变；当前Unity真实模型选择后的弃牌/跳过实际确认；迟到/状态变化与急停；连续运行仍需验证。不能把300+0后台联调算成5+10速度验收。
