# 完整场况的具名列传输

DEV-067开发前方案。5＋10 short-v5保留失败：17个机会中16确认，第17次未在剩余期限形成有效动作。后段请求约一万input token；公开事件与牌河重复字段名占明显篇幅，规则和组装主要为数十毫秒。继续缩短传输应保持全部时序和事实。

新增独立版本`mj.tables.1`，仅将public_events及四家river的对象数组投影为具名列：columns保存每种实际字段集合，rows每行第一个整数指向列集合，剩余值与列名顺序一致。所有值、条目顺序、重复项、缺省字段与显式null均可精确还原。手牌、动作、动作旁牌效与役种保持可读；不沿用曾出现理解问题的深层事实引用。

模型说明包含列读取规则，计入真实usage。统一事件ID读取及反向投影，计划引用仍只允许本请求事件，短ID恢复为原事件。每次仍发送独立完整当前上下文，不延长对话。新增`table_wire_validated=false`独立门禁，默认仍用既有可读格式；只有真实等价/理解/usage对照没有已知退化后，才可在本机停接管时启用。

验证先覆盖空数组、字段缺失/显式null、多种事件形状、红牌和多组合、长牌河及计划引用；再复用配对工具的同场况真实模型读取与选择，保留所有失败和格式分歧。增加首动作计时探针对同一组完整局面交替请求两格式，只做离线渠道调用，不碰生产游戏。对照不证明长期成绩或正式5＋10实战通过；负收益或关键理解错误维持旧格式，记录原因。500窗口与三完整场继续由VAL-005/006跟踪。
