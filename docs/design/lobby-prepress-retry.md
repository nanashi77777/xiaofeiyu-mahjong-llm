# DEV-093 · 大厅按下前渲染失效的有限恢复

真实建房准备中出现TargetExpired，发生在鼠标按下之前。大厅适配器增加独立单层最多三次重观察/定位，所有尝试共享一次控制动作的八秒截止。仅明确的TargetExpired且按下回调尚未触发允许重试；停止/Esc、状态/几何改变、歧义、其他异常及任何可能按下后错误均不重试。每次重新核验同一scene/control，不改选项。

提交日志标记移动到真实按下前回调，先落盘再发送；渲染超时且尚未回调不产生已提交假象。后台和物理模式共用此边界。停止到达仍撤销，租约不提前释放，不给创建/匹配/准备等动作重复副作用。

回归覆盖首次渲染失效后成功、三次耗尽、可能按下后错误、原截止、停止、状态变化及提交最多一次。新完整实战使用加载该版本的新服务和新报告；旧建房失败保留，不改成成功。
