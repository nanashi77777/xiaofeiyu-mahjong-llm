# 候选模型对照试用

用户于本轮新增指令：麻将模型切到候选模型看看改善，若不明显则换回。该最新指令优先于原固定基线模型约定，试验不更换专用密钥、不启用推理或本地策略。

先在真实停止接管时对同一归档局面，完整当前生产格式、单请求short首动作进行交替基线模型/候选模型比较；每次独立上下文，schema和none相同，记录首动作/首文本/完整响应、usage/失败。使用首中末及原失败窗口覆盖输入规模，至少12组。副请求保持0以隔离模型变化，不把输出全长当首动作时间。

改善判断先看合法性/失败不恶化，首动作P50目标降低至少约20%、五秒内比例明显增加，尾延迟不明显恶化；小样本只作去留筛查。若总体差异小、候选理解/合法率退化则回基线模型；有明显收益才切服务决策与复盘为候选模型并以独立5＋10短场确认。新模型格式理解在同样事实读取样本核验，不沿用基线模型结果为候选模型背书。

任何实测仍保留失败，不混入旧基线模型成功；完整500窗口和三场继续按真实结果验收。配置选择和实际结论写完成日志，必要时默认仍基线模型。
