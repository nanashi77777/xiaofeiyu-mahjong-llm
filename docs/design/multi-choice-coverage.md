# 三吃及更多组合的观察覆盖

DEV-068开发前方案。DEV-066已支持任意数量分组和多行，但本机旧combo_region仅为双吃校准的390像素宽区域，更多组合可能落到裁剪外；仅在更大测试ROI通过不能证明生产具备观察覆盖。

由已校准区域建立更宽的菜单观察带，横向覆盖画布，纵向可容纳校准行及其上方菜单行，底部以校准手牌区域为硬界。原区域仍必须合法；不能扫描整图后把牌河或手牌当作菜单。每一个可见组仍按全部服务器组合核对，缺组、额外组、重复、低置信、裁边牌面一律拒绝。扩大只影响本地截图裁剪，不修改浏览器视口或取图参数。

验证使用真实旧双吃画面与明确构造三吃、五种赤牌变体、双行、左右越出旧ROI、手牌排除及边界截断。分类替身与真实字形核验分别标注；实际三吃点击仍由VAL-003记录自然出现的机会，不人为代替模型选动作。
