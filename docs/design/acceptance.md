# 首版验收标准

## 完成含义

实现任务完成表示源码与该任务必要验证完成；综合验收有独立 VAL 编号。所有必需 VAL 通过才称首版完成。文档、离线、模型能力、隔离输入与真实实战分别提供证据，不相互代替。

性能/效果优先级：合法动作与真实执行一致 → 五秒级及共享池不耗尽 → 正确认识役种和无役风险 → 简短解释、具体小局计划、点差下的攻守与长期经验。首版没有保证升段、固定平均顺位或必然通过学习提高成绩的承诺；这些指标持续记录。

## 特殊场景范围

普通弃牌、赤五、重复牌摸切、吃多组合/碰、立直按钮与弃牌、立直声明被荣和、明暗加杠、抢杠、岭上、海底河底、振听与过和、多家和、荒牌/九种九牌/四风连打/四家立直/四杠散了等标准可发生场景、连庄、西入和实际终场，按规则配置专项覆盖。

低概率情况以脱敏真实事件或明确构造事件加隔离输入验证，不要求三场实战自然出现全部特例。构造样本不能冒充真实抓包。库未支持的标准选项必须补适配验证；三麻/地方役不算标准四麻验收范围。

## 速度报告口径

每个本家行动窗口计一次机会，复合 UI 点击算一次完整操作；吃碰后新弃牌窗口另计。客户端本来被迫自动动作单列，不进入“模型主动操作”分母。模型失败、程序异常导致自动摸切不能归入被迫动作来规避失败统计。

同时公布所有机会数、有效模型响应、成功落实数、五秒内成功数、超五秒数、计时耗尽数、修复/补点数、意图与实际不一致数。耗时分位对可测完整操作报告，失败分母另列清楚；五秒成功率分母使用所有应由模型主动处理的机会。

正常条件与故障注入分开；故障注入用来证明取消、保存与诊断，不要求故障时也保证不断线。真实网络/API异常仍如实记为失败，不用传统算法兜底。5＋10计时回放不是完整对战模拟器，报告明确采用的输入耗时来源和与真实时钟的差别。

## 实战条件与证据

VAL-006原对局验收由已进入的AI友人场开始，物理模式保持前台，后台模式另核验最小化输入。2026-10-31新增的自动登录、按指令段位匹配与友人房加入/创建分别进入VAL-012/013，见lobby-automation.md；不能用大厅导航成功冒充完整AI对局验收。验收保存本机事件、动作证据、终场截图/结算、脱敏结果摘要与耗时报告。不能取得实战条件时保留待验收，不虚报首版完成。

最终检查最近二十场范围内每条大牌都关联正确场和小局，完成结果与中断点数分离，重启没有重复场次，QQ 能查询但不能控制游戏。经验只需证明机制正确和有据可查，不能用少量样本宣称打法已经显著提高。

紧凑格式见[传输契约](model-wire-format.md)。输入语义等价不自动等于模型理解无损；VAL-010必须使用真实渠道配对比较，失败则回退直观表达。不得用字符数下降冒充token下降，不能将缓存命中当作结构本身节省的token。
