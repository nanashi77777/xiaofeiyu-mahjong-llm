# 已校准手牌的少张边界与字形变体

## DEV-091：已知字形与自动学习分别判断锚点

四副露后的待弃牌可能只有两张。完整数量、顺序、赤牌、独立摸牌位置和每一张字形均通过时，不再要求三种不同锚点；只有确实需要学习未知的可用字形才保留三种锚点要求。未知置灰字形仍拒绝，不能根据排序推测。补回归覆盖一至两种已知牌、四副露摸切实例、未知字形拒绝以及足锚点学习。

## DEV-092：反光变体与白板空白的独立验证

真实失败帧中的赤五反光导致原模板未通过；保留失败报告，允许每张牌具有多个本机独立校准变体，以原阈值逐一核验，不在失败时以权威排序覆盖模板。校准的缺失、非法尺寸、错误字形和赤普通五混淆继续拒绝。

空白白板的常量模板不能用归一化相关度：该算法可对任意区域返回1。只对白板允许专门空白核验，要求内区空间变化和与校准颜色的误差均受限，置灰与明亮分开比较；其他低细节模板拒绝。白板立直选择仍需服务端提供、完整牌面映射及可用白色牌面，不以空白区域随意定位。
