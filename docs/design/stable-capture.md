# 稳定画布取图

日期：2026-10-31（Asia/Shanghai）。用户观察自动操作时画面反复伸缩。关联DEV-046，先暂停输入再修复。

现有画布元素截图采用CSS比例clip；后台保帧还请求低分辨率screencast。多次取图未测得JS窗口/画布几何变化，但这些渲染缩放路径应从输入定位中移除。改用CDP截取当前完整视口，不传clip/scale、不滚动、不设置设备度量；图像返回后仅在Python中裁剪画布并归一化到CSS像素。保帧用原视口尺寸，帧立即丢弃。截图加单一锁，取图前后几何必须一致，否则拒绝用于点击。

验收：隔离真实Chromium在DPI缩放及非全屏画布中连续取图，窗口/DOM/画布几何不变，裁剪内容与尺寸正确；截断及取图期间变更拒绝；后台最小化取图/渲染仍可用；真实客户端连续取图有本机证据。用户感知的伸缩不能仅以JS resize事件为零就宣称已消失。恢复房码与准备测试前必须采用新链路，不再使用元素截图诊断。
