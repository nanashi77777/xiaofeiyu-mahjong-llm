# 加入友人房后的准备

日期：2026-10-31（Asia/Shanghai）。用户要求加入房码后能点击准备，授权使用54321进入并准备。关联DEV-045，实施前登记。

JoinFriend增加ready布尔参数，默认true；明确只入房时可传false。QQ工具、HTTP/CLI和面板采用相同契约，已有创建房间不因此自动开始。已有命令按原ID返回历史记录，不重放；新参数不同内容仍拒绝复用同ID。旧版本已存无ready字段的命令不自动执行新增准备。

流程：画布数字键盘原样输入并读回房码→点击加入→按回包核验房号→持久记录加入确认→识别加入者的“准备”按钮→记录准备提交标记→单击→等待readyPlay成功回包。只读观察readyPlay请求/响应及脱敏准备通知，不保留账户ID/昵称/认证。房主的“开始”与加入者的“准备”必须是不同的可见模板，不能因按钮位置相同而替换。

加入和准备是两个提交步骤，持久保存各自确认与未知状态。加入已成功而准备失败/等待页面时，续跑只在同一当前房间、未开局且按钮明确可见时执行尚未提交的准备；准备已提交但结果未知则不再点。成功回包才能报告prepared=true。离房、重连失去房间事实、被踢或对局开始时旧准备定位失效。外部房主可在准备后开局，本流程不点开始，也不据此启用尚未验收的自动打牌交接。

专项验证：默认/显式false与严格类型、当前房号保护、房主开始按钮拒绝、等待中的入房恢复、准备确认/失败/未知不重复、敏感协议字段隔离；真实54321输入/加入/准备分别记录。QQ测试不发消息，保持白名单和导航令牌权限。完整DEV-039/041与VAL-012/013未完成范围继续跟踪。
