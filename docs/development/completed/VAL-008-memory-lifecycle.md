# VAL-008 · 经验修订、后续生效及召回追踪

类别：验收。完成日期：2026-10-31（Asia/Shanghai）。

专项验证采用隔离生命周期故障注入加生产只读审计，未人为修改正式经验，也未向QQ发消息。

tests/test_review_lifecycle.py、test_queries_and_model.py在隔离数据库验证：真实可追事件才能支持候选；同一场多次复盘不能凑复核数；后续三个不同且时间确实更晚的场次与反例检查后才可stable；修改主张/适用条件退回candidate并重新计支持；反例、修订、inactive历史保留；新场冻结和按情境召回，新增经验不进入已开始的场，停用/改变主张立即失效；风格轴范围受限且不改合法候选。错误批次事务回滚，抢占、重启、三次尝试上限和活动场旧队列撤销均通过。全量207项pytest、ruff通过。

实际证据由tools/audit_memory_evidence.py只读生成runtime/memory-provenance-v1.json：6条经验的7个版本，7个版本均candidate、无stable/ inactive版本；15次真实场冻结，500条非空召回，其中418条已经关联模型决策记录。全部召回ID/版本在该场冻结和经验历史中存在，所有支持/反例事件可追，役种参考版本可定位，错误数0。82条只有召回记录未形成决策不冒充有效模型选择。该数字是此时审计快照，不是性能500窗口验收。

生产复盘历史中存在真实模型总结及经验候选，实时只使用有可信标签的投影；用量按麻将专用凭据记录。隔离实际模型资料查询另有runtime/yaku-reference-validation-v1.json，但它的构造经验没有写入正式库。没有正式经验因验证工具被提升稳定；稳定/停用/反例路径以明确构造隔离场证明，未假称自然实战已产生稳定策略。

本项证明可修订经验确实能供后续模型参考及证据链正确，不证明平均顺位或胜率已提高。经验不能改客观牌谱、代码、权限、系统指令或正式成役条件；役种更正走版本控制。真实牌局、实时速度及QQ整体权限仍由其他VAL单独验收。
