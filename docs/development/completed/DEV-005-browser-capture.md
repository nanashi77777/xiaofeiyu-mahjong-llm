# DEV-005 · 专用浏览器与被动采集

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

Browser使用独立runtime/browser-profile、专用Chrome/CDP端口及绑定页面，被动监听WebSocket收发帧。Executor绑定时核对浏览器实际PID，拒绝同机Steam雀魂等其他进程。采集器只解码游戏/大厅白名单；认证请求仅保留临时账号到座位和对局映射，登录载荷、Cookie和操作凭据不进入模型或牌谱。

页面导航和游戏连接关闭同步使旧operation失效，保存interrupted并通知取消；失焦不会改变牌局，物理模式停止输入，后台模式有独立选择。原生视口截图不请求缩放/设备覆盖，捕获前后核对几何；布局变化或裁切拒绝定位。JPEG90的本机对照捕获109～140ms，PNG813～875ms，五次手牌核对通过；端到端性能仍待VAL-005，不能将截图单项改善当作整场五秒通过。

验证：完整回归中的浏览器几何、串行捕获、连接即时失效、专用进程绑定、后台输入和认证脱敏测试通过。真实多场友人局通过专用浏览器持续采集，300+0半庄到真实终场；另5+10故意超时场验证后重启，已记录中断，恢复后服务端未报告可续对局，不计续局验收。当前完整回归结果见同批进度日志。

实现：browser.py、protocol.py、engine.py、execution.py。真实协议专项在VAL-001，鼠标完整矩阵在VAL-003，未来视觉状态输入保留Event.source=vision和同一领域入口。回退恢复相关Git源码；不删除本机事件。Git关联由注册表和提交索引补入实际提交。
