# DEV-098 · 开局前预备自动接管与首个行动窗口

完成日期：2026-11-04（Asia/Shanghai）。用户明确要求对局开始前即开启自动接管。本任务仅修改麻将AI项目，QQ主项目只读，实战与综合验收保持暂停。

## 实现行为

所有QQ及本机房间start都先验证房间和本机模型配置、绑定专用窗口并检查停止状态，持久保存一次性接管授权，成功后才允许开始点击；兼容旧QQ工具默认takeover=false。已有真实arm复用同一任务和原授权期限，不重新计时。shadow预备不能静默升级为真实输入；房间、会话、输入停止或授权过期变化均阻止开始。

开始点击完成立即释放房间输入租约，等待startRoom回执不阻塞已经预挂的接管任务。真实首局完整时自动进入原Coordinator模型与执行链路；即使首个操作事件先于开始回执到达，也不需要QQ再调用一次。其余房间操作保持原输入租约范围。实际牌局、合法候选、真实行动截止和时间池均保留原来源。

start/shadow在尚未入局时预备一次自动接管。面板按钮改为“开启自动接管”，预备状态显示“接管已预备”；status.autoplay_prepared及startup区分预备、shadow和实际enabled。人机房添加电脑请求返回固定原因和房主开始提示，避免沿用普通四人房添加机器人的步骤。

开始前失败或明确拒绝撤销本次授权；提交未知保留有界等待且不重按。重复命令返回原结果。停止/Esc/重启不复活预备；房间绑定后不能转授另一房间。
