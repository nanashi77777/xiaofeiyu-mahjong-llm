# DEV-007 · 权威事件与幂等归并

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

Engine以认证后的游戏连接接收事件，按场UUID、小局签名、source step和类型生成稳定身份，重复通知不重复消费手牌/副露或扣点。reducer采用深拷贝，只由实际游戏事件更新牌河、摸切、赤牌、副露消费/叫入来源、杠升级、宝牌和立直声明/成立。模型意图、计划和经验保存在独立records，无法调用状态写入口。

可见本家实体计数、同牌枚数、叫入牌和有效13/14张等式均校验。未知动作或缺牌消费保存对应游戏证据、标记gaps并关闭operation。服务器接受当前窗口的cancel_operation且原窗口可荣和时，新增ObservedPass事实，区分临时与立直后过和振听；拒绝/迟到/重复ack不能制造这一事实。摸牌只清临时振听，立直振听保留。

验证：赤牌摸切不匹配拒绝、被鸣牌不重复计可见数、暗杠补牌/加杠、立直成立扣点、重复/重放幂等、多家和、断线立即作废，以及接受过和/重复ack/振听清除测试通过。真实长期联调场已记录多次弃牌、跳过、碰、吃、立直和荣和服务端确认；这些不替代VAL-001全专项和VAL-006完整无干预验收。

实现：engine.py、state.py、domain.py、store.py。全量回归见同批日志。回退源码不覆盖已有append-only事件；涉及重建先备份本机库。Git关联由注册表和提交索引补入实际提交。
