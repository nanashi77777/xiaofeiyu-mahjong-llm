## 真实故障与修复

本机持久命令显示房间开始前已保存一次接管授权，开局后授权也实际成功；首个行动随后在调用模型前以KeyError失败。只读真实归档复现定位到联合经验召回排序：两条历史mahjong.memory.v1记录缺少后来增加的applies_to，旧的独立召回允许缺省，但新联合排序直接取键导致异常。原场失败继续保存，不作为成功窗口。

联合召回现在仅在读投影补入旧版的默认语义：kind=lesson、applies_to为空、preference=None。保留原文、条件和例外、版本、证据；不改数据库，不删除旧经验或关闭记忆。已有范围过滤、冻结版本、停用与教学可信标签继续生效，合法候选不变。

实际状态还显示应用输入模式后接管被关闭。本机接口现在先验证模式，相同模式直接返回unchanged；不会撤销等待、停止决策、清除用户停止或释放后台会话。QQ操作接口也支持相同模式的幂等返回，不要求先停机。真正切换仍保留原来的停止/空闲边界，非法参数无撤销副作用。

初次服务重载后，专用窗口实际最小化，页面停在资源加载；只读帧试验证实原生screencast可以恢复后台帧。后台模式现在在已验证专用页面绑定后、reload之前启用既有的原生画面保活；失败时释放会话。没有调整系统鼠标、前台、窗口尺寸或渲染缩放，没有提前点击。
