# DEV-061 · 多枚赤五和对手暗杠颜色未知

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

算点库的136牌编码每门只预留一枚赤五，原分配在实际同花色两赤时会失败。现按牌种分配物理实例，库负责牌形、役、符和普通宝牌，本项目按手牌及副露中实际0编码独立计赤加番并用同一计分配置重算支付。没有役时不能靠赤宝变为可和；役满不加赤番，累计役满与切上等房规保持。

对手暗杠只给tiles牌种字符串时，原先把0p扩成四枚0p会编造颜色。现在用四枚基础牌种及red_count_unknown=true明确颜色缺口；这时tiles表示牌种，不表示四枚确定普通五。无赤规则及自家可知的实际消费保留确定颜色。不给未知暗杠猜赤牌分布，模型契约明确该字段含义。未增加牌谱事件字段，标记只在可重建快照里。

实现位置：domain.py、state.py、rules.py、wire.py。207项pytest和ruff通过；test_red_multiplicity.py验证双赤、赤副露、无役、役满不加赤、对手0/5编码、无赤规则及自家暗杠。test_yaku_reference_matrix.py交叉核对45个普通役/役满的值和门清条件，既有累计/双倍/复合/切上矩阵仍通过。

限制：这是明确构造牌局专项，当前v14旧服务尚未加载，不能写成真实对手赤五暗杠已验收；后续受控重启加载。VAL-002/011记录规则与参考范围，真实整场依然独立。
