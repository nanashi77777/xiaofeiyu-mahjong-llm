# DEV-048 · 离开提示检测、恢复与验收归因

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

生产5+10失败停止后，客户端显示离开自动摸切提示。ClientGuard仅在接管授权仍有效时、空闲事件间隙识别已校准的完整提示与“我回了”标签；先取消旧决策并等待释放输入，再通过同租约点击非策略恢复按钮。控制generation在期间改变时禁止自动重启，用户停止优先。新鲜模型窗口仍经指定模型决策，没有自动选牌或跳过。

验证：124项pytest通过；两个隔离用例验证可见恢复、旧决策停止/租约释放、用户后续停止不被覆盖且无决策写入。真实生产服务记录client_away observed与resume_clicked，之后模型选择弃牌实际确认。并行目标缓存也已实际命中，2次普通弃牌input_ms约141/203、read_to_mouse约3813/3031；少量样本不代表整体五秒验收通过。

实现位置：src/majsoul_llm/client_guard.py、app.py、coordinator.py、validation.py及tools/practice_suite.py。正式suite遇到client_interventions停止并保留报告；恢复后的混合开发场不能计完整无干预场。

限制与后续：未知提示或缺少校准保持停止/诊断，不任意点击；VAL-003/005/006继续。Git关联：本批实际提交后补入注册表及索引。回退通过Git恢复相关源码与测试，保留本机所有失败、客户端行为和恢复记录。
