# DEV-053 · 空闲手牌预观察与像素核验缓存

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

根据用户补充要求，等待他家阶段可预先核验本家手牌位置；触发模型决策时仍并行观察本窗口全部可见候选。手牌签名包含场/小局、每张牌、摸牌槽、副露及起手状态。跨事件只有签名、截图尺度和校准版本一致，且新截图手牌区域逐像素相同时，才复用已核验的实例映射；牌面或可见像素改变即完整重识别。点击目标仍使用新截图时间与当前布局，原新鲜度阈值未放宽。

实现位置：locator.py、execution.py、app.py和coordinator.py；vision_cache显示命中/失效与空闲任务。空闲观察和实时观察/输入共用租约，取消线程识别也须等待其结束释放，不能造成鼠标重叠。

验证：136项全量回归包含映射缓存命中、状态版本变化、像素/摸牌槽失效；新增两个空闲专项通过，证明无策略动作、相同手牌不重复、手牌变化重验和取消期间租约不提前释放。生产流式场前16次决策时实际hand_hits=48、hand_misses=54，idle_active=true；未将这些次数冒充节省毫秒。既有并行测试证明模型等待读取而读取可先完成，模型失败无点击。

限制与后续：每次摸牌通常会使手牌签名变化，需重新确认；缓存不代替点击前状态/布局复核，也不能预识别尚未出现的立直选牌或多组合菜单。实际五秒收益随VAL-005记录。
