# DEV-057 · 渲染帧等待失败的按压前后分类

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

真实short 5+10场第28机会在初始悬停帧确认时超时，源代码位置在mouse.down之前。此前统一抛TimeoutError，执行器未使用已有的按压前重取机制，随后保守记录execution_uncertain并暂停。该真实失败保留，不能算一次成功点击。

仅将这一明确尚未按下的路径改为TargetExpired，复用Executor既有至多三次同语义目标重取；每次重新识别、重新核对原窗口/状态/停止和同一deadline。不延长帧等待阈值或行动预算，不把模型动作替换为别的选择。实际按下后的帧等待失败仍必须释放并返回mouse_sent，不能借此重按。

验证：147项全量pytest和ruff通过。背景输入专项证明初始帧失败只有move、没有down/up，抛精确的按压前类型；执行生命周期回归证明仅TargetExpired可以重新取同一语义目标、未知按压异常只尝试一次；按下后场景变化仍只按/抬一次并保留sent。真实旧失败及其9813ms耗时在runtime/production-5plus10-short-v1.json完整保留。
