# DEV-064 · 低频按钮与鸣牌菜单核对

类别：实现；完成日期：2026-10-31（Asia/Shanghai）。

## 变更与原因

自摸、三类杠及九种九牌按钮缺少校准，合法模型动作可能无法执行。新增tools/calibrate_buttons.py，使用本机真实截图显式manifest裁剪，记录原图哈希/裁剪和同源自验或独立截图类型；只在本地缩放/底部裁剪补边，验证字形，不声称老画面的几何就是当前窗口。安装前核对生产输入空闲、备份profile，再原子替换配置；截图和校准内容留ignored runtime。

ScreenLocator允许同语义多个字形；同一位置命中去重，多个位置拒绝，不能凭最高分选择一个。三类杠共享字形，动作类型和消费牌仍由原合法模型动作决定。完整组合模板命中也必须先核对当前菜单全部选项，修复原先模板捷径绕过候选核验的问题，防止缺项/错赤牌菜单被接受。

另发现原缺按钮诊断只保存最早0.35秒已有帧，实际留到的杠画面还在出牌动画中、没有按钮。现在按0.35/0.9/1.6秒三个阶段各最多保留一个原有观察帧，不额外截图或点击，让后续实际按钮可供校准。
