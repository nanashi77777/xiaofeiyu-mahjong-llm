# DEV-020 · 真实鼠标事务与急停保护

实现任务与本机必要验证完成。正式WindowsMouse保存位置、核验绑定进程/前台/窗口几何和目标新鲜度，移动至目标后按下/释放并归位；输入期间人工移动后不覆盖其新位置。停止、Esc、过期、失焦和被遮挡均阻止后续输入。
