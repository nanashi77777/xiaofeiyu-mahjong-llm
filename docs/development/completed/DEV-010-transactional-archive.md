# DEV-010 · 最小增量牌谱与中断保存

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

SQLite WAL将单条真实事件与最新状态缓存同事务提交，事件是唯一历史事实。rounds引用小局结果事件，wins引用场/小局/和牌事件及hules下标，不重复存原文；matches仅一份最新缓存，public_events由事实重建。模型、回执、token和复盘各自进入独立records，经验修订独立存储。

v1→v2升级先备份，再原子转换事件包装、移除重复小局/和牌载荷；更高未知schema拒绝打开。查询/导出保留中断场，终场分数与last_observed分离。重启按同UUID续录，已有事实和小局/大牌身份去重，事件顺序可恢复导出。整场partial/gaps不因下一小局完整而变full。

验证：构造完整/中断/多家和回放、迁移前后事件与投影等价、重复恢复不增行、已提交数据关闭重开后保留、未知新schema拒绝。前轮真实4场289事件迁移已备份且等价，最小牌谱JSON减少68.44%；本轮持续保存故意超时场与开发失败，没有将它们伪装成完整成功场。当前完整回归见进度日志。

实现：store.py、state.py、tools/compact_archive.py和只读查询。真实完整三场/恢复/最近二十场验收仍在VAL-001/006/007。回退程序版本时使用迁移前备份副本，不能让v1程序改写v2原库。Git关联由注册表/提交索引补入。
