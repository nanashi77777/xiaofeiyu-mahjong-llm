# DEV-058 · 同帧识别去重与低频按钮证据

类别：实现。完成日期：2026-10-31（Asia/Shanghai）。

同一不可变截图对象在手牌、牌面学习和多个按钮识别间复用解码及归一化结果。缓存只保留最新一帧，并以原始bytes对象身份及归一化尺寸校验；新帧、新尺寸重新处理，归一化数组只读。像素一致性、手牌签名、候选、布局、目标新鲜度和行动deadline校验保持原约束。

现有并行观察遇到尚未校准的合法按钮时，在窗口成熟后保存已取得的帧及match/round/window/state依据，每窗口每缺失种类一次。文件仅在runtime/calibration/offered，标注extra_captures=0；不额外取图、不决定动作、不启用未核验字形，写盘失败不影响模型原选择。实现位置为locator.py和execution.py。

验证：全量149项pytest通过，ruff通过。新增test_frame_reuse.py覆盖同帧复用、只读、新帧和尺寸失效、纵横比拒绝及证据留存去重；原并行观察撤销、过期识别和输入租约回归仍通过。

同一真实归档帧的碰/跳过双按钮识别各测8次，新版每次使用新的bytes对象模拟新帧，只在一次双按钮内共享。中位耗时从339.615ms变为299.359ms，所有坐标相同（碰[771,623.5]、跳过[992.5,624.5]）。原始报告runtime/vision-baseline-v1.json及runtime/vision-reuse-v1.json留本机，零UI输入、零模型调用。样本小且测量时段不同，此约40ms差值不能用于宣称端到端性能达标。

限制：新证据采集尚待重启后的真实低频操作窗口产生资料；自摸、各杠和九种九牌等完整视觉矩阵继续在DEV-019、VAL-003跟踪。正式5+10、三场及95%五秒目标未通过。本项仅消费已实现并验证的帧复用和诊断能力。
