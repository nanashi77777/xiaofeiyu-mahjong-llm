# DEV-065 · 面板慢请求与重连隔离

类别：实现；完成日期：2026-10-31（Asia/Shanghai）。

## 变更与原因

原fetch没有期限，连接建立后服务不返回或响应体挂起会长期占住refreshing，断线标记也不能出现。正式panel.html为整个fetch+JSON解码设置5秒查询期限、15秒控制期限，同时AbortController取消网络；超时释放轮询锁并明确旧数据未知。

手动连接切换取消旧代次请求并立即开始新轮询，旧成功/错误不能覆盖新状态。停止入口独立于状态轮询锁；控制提交超时报告结果未知，提示先核对实际状态，不自动重复提交。接口明确失败响应仍显示实际错误。

## 验证

tools/validate_panel.py加载正式HTML，独立headless、全部路由拦截；runtime/panel-validation-v2.json的20项通过。除原13项外新增挂起无响应后恢复、响应体挂起期限、POST超时只提交一次且结果未知、重连替换旧请求、旧结果不覆盖新状态、轮询挂起期间停止仍提交。生产控制、对外消息均0。

同批全量239项pytest和ruff通过；此HTML独立浏览器验证覆盖真实JavaScript请求控制，构造fetch仅用于明确注入无响应/响应体挂起，不接触生产游戏。最后740px页面截图保留本机。
